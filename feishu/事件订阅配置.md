# 飞书事件订阅配置指南

## 1. 配置事件订阅请求地址

在飞书开放平台 → 你的应用 → 事件订阅：

1. 请求地址填写：`http://<你的公网地址或内网穿透地址>/webhook/feishu-trigger`
2. 点击「保存」，飞书会发送验证请求
3. n8n 工作流需要返回 challenge 值完成验证

### 本地开发使用内网穿透

如果 n8n 运行在本地（localhost:5678），需要使用内网穿透工具：

**选项1：ngrok**
```bash
ngrok http 5678
# 得到类似 https://abc123.ngrok.io 的地址
# 事件订阅地址填：https://abc123.ngrok.io/webhook/feishu-trigger
```

**选项2：frp**
```bash
# 需要有公网服务器，配置 frpc.ini
[common]
server_addr = your-server-ip
server_port = 7000

[n8n]
type = http
local_port = 5678
custom_domains = n8n.your-domain.com
```

**选项3：部署到云服务器**
将整个系统部署到有公网 IP 的云服务器，直接用服务器 IP 或域名。

## 2. 订阅事件

添加以下事件：

| 事件类型 | 事件名称 | 用途 |
|---------|---------|------|
| `bitable.record.changed_v1` | 多维表格记录变更 | 内容状态变更时触发改写 |
| `im.message.receive_v1` | 接收消息 | 机器人指令触发（可选） |

## 3. 事件数据格式

多维表格记录变更事件的数据结构：

```json
{
  "schema": "2.0",
  "header": {
    "event_id": "xxx",
    "event_type": "bitable.record.changed_v1",
    "create_time": "xxx",
    "token": "xxx",
    "app_id": "xxx",
    "tenant_key": "xxx"
  },
  "event": {
    "app_token": "Cq7nbbmo3awBwos1n7acviggnEd",
    "table_id": "tbl9QekjLz3G1BzL",
    "record_id": "recxxx",
    "action": "record_changed",
    "fields": ["状态"]
  }
}
```

## 4. n8n Webhook 验证配置

n8n 工作流的 Webhook 节点需要配置：

- **HTTP Method**: POST
- **Path**: feishu-trigger
- **Response Mode**: Last Node
- **Response Data**: All Entries

在工作流开头添加一个「IF」节点，判断是否为验证请求：
- 如果 `body.type === "url_verification"`，直接返回 `body.challenge`
- 否则继续执行改写流程

## 5. 权限要求

确保应用已开通以下权限：
- `bitable:app` - 多维表格读写
- `im:message` - 发送消息
- `im:message:send_as_bot` - 以机器人身份发消息

## 6. 测试验证

1. 在多维表格中新建一条记录，状态改为「待改写」
2. 检查 n8n 执行日志（Executions），确认工作流被触发
3. 检查多维表格，确认改写结果已回写
4. 检查飞书群，确认收到通知消息
