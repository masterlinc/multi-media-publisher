# 飞书配置指南

## 一、创建飞书应用

### 1.1 创建企业自建应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 进入「开发者后台」→「创建企业自建应用」
3. 填写应用信息：
   - 应用名称：新媒体一键发布
   - 应用描述：多平台内容自动发布系统
   - 图标：上传自定义图标

### 1.2 获取凭证

创建完成后，在「凭证与基础信息」页面获取：
- `App ID` → 填入 `.env` 的 `FEISHU_APP_ID`
- `App Secret` → 填入 `.env` 的 `FEISHU_APP_SECRET`

## 二、配置权限

在「权限管理」中开通以下权限：

### 2.1 多维表格权限
- `bitable:app` - 查看、评论、编辑和管理多维表格
- `bitable:app:readonly` - 查看多维表格
- `drive:drive` - 查看、评论、编辑和管理云空间中所有文件

### 2.2 消息权限
- `im:message` - 获取与发送单聊、群组消息
- `im:message:send_as_bot` - 以应用的身份发消息

### 2.3 文档权限
- `docx:document` - 查看、评论、编辑和管理云文档
- `wiki:wiki` - 查看、评论、编辑和管理知识库

### 2.4 日历权限（定时发布用）
- `calendar:calendar` - 查看、编辑和管理日历

## 三、创建多维表格

### 3.1 新建多维表格

1. 在飞书中新建多维表格，命名为「新媒体内容发布库」
2. 按照 `多维表格设计.md` 中的字段设计创建字段
3. 记录多维表格的 Token：
   - URL 格式：`https://xxx.feishu.cn/base/【Token】?table=...`
   - 将 Token 填入 `.env` 的 `FEISHU_BITABLE_TOKEN`

### 3.2 添加应用为协作者

1. 打开多维表格
2. 点击右上角「分享」→「添加协作者」
3. 搜索刚才创建的应用名称，添加为「可编辑」权限

## 四、配置飞书机器人

### 4.1 启用机器人能力

1. 在应用后台 →「添加应用能力」→ 启用「机器人」
2. 配置机器人名称和头像

### 4.2 创建群聊机器人（Webhook方式，推荐）

1. 在飞书群聊中 → 设置 → 群机器人 → 添加机器人
2. 选择「自定义机器人」
3. 记录 Webhook 地址，填入 `.env` 的 `FEISHU_BOT_WEBHOOK`
4. 安全设置：可选择「签名校验」或「IP白名单」

### 4.3 机器人使用场景

- 发布结果通知（成功/失败）
- 每日内容排期提醒
- 异常告警（服务宕机、发布失败）
- 数据日报推送

## 五、配置事件订阅（n8n触发用）

### 5.1 配置请求地址

1. 应用后台 →「事件订阅」
2. 请求地址填写 n8n 的 Webhook URL：
   `http://你的服务器IP:5678/webhook/feishu-event`
3. 点击「保存」，飞书会发送验证请求，n8n 需要返回 challenge

### 5.2 订阅事件

添加以下事件：
- `bitable.record.changed_v1` - 多维表格记录变更
- `im.message.receive_v1` - 接收消息（机器人指令）

## 六、n8n 飞书节点配置

### 6.1 安装飞书社区节点（可选）

n8n 内置了飞书相关节点，也可以安装社区增强节点：

```bash
# 在 n8n 容器中安装
docker exec -it media-n8n npm install n8n-nodes-feishu
docker restart media-n8n
```

### 6.2 配置飞书凭证

在 n8n 中：
1. 新建 Credential → 选择「Feishu」或「Lark」
2. 填入 App ID 和 App Secret
3. 测试连接

### 6.3 常用飞书节点

| 节点 | 用途 |
|------|------|
| Feishu - Bitable | 读写多维表格记录 |
| Feishu - Message | 发送飞书消息 |
| Feishu - Document | 读写飞书文档 |
| Webhook | 接收飞书事件回调 |
| HTTP Request | 调用飞书开放API |

## 七、测试验证

### 7.1 测试多维表格读写

1. 在多维表格中新建一条记录
2. 在 n8n 中创建工作流：Webhook 触发 → Feishu Bitable 读取记录
3. 验证能正确读取到新建的记录

### 7.2 测试机器人消息

1. 在 n8n 中创建工作流，添加 Feishu Message 节点
2. 配置发送到指定群聊
3. 执行工作流，验证群聊收到消息

### 7.3 测试文档读取

1. 创建一篇飞书文档作为母稿
2. 在 n8n 中用 Feishu Document 节点读取内容
3. 验证能正确获取文档正文

## 八、常见问题

### Q: n8n 无法连接飞书 API？
A: 检查服务器网络是否能访问 `open.feishu.cn`，确认 App ID/Secret 正确，应用已发布上线。

### Q: 多维表格记录变更事件收不到？
A: 确认事件订阅的请求地址可从公网访问，n8n 的 Webhook 已启用，应用已添加为表格协作者。

### Q: 机器人发消息提示权限不足？
A: 检查应用是否已开通 `im:message:send_as_bot` 权限，机器人是否已加入目标群聊。

### Q: 本地开发没有公网IP？
A: 可以使用内网穿透工具（如 ngrok、frp）将本地 n8n 端口暴露到公网，或直接部署到云服务器。
